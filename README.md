# 67-LUBENITE

Un joc simplu de browser cu două mașini care pot face accident.

## Cum rulezi jocul

1. Deschide `index.html` sau `cars.html` în browser.
2. `index.html` este jocul clasic cu o mașină și un adversar automat.
3. `cars.html` are două mașini controlabile: roșie cu W A S D și albastră cu săgeți.
4. Dacă mașinile se ciocnesc, apare mesajul `ACCIDENT!`.
